# Visión — CRM de captación San Rafael 360

Fecha: **17 de septiembre de 2026**.

## En una frase

Mesa de captación **aislada** para que Diego (tenant 0) cargue contactos a mano o pegue el JSON de cualquier IA, encole WhatsApp (`wa.me`) y registre actividad **sin tocar** el cupo ni las fichas de la guía.

## Cómo encaja

| Capa | Rol |
|---|---|
| Guía pública | Receptiva. No cambia. |
| Admin Places / Prospección / Alta / Interesados | Producción de Diego. Intocables hasta que el CRM las cubra. |
| Este CRM (`/portal/crm`) | Tu mesa, hoy. Más adelante, el mismo producto para clientes que lo paguen. |

Grok u otra IA actúan **afuera**. El módulo pone el prompt; se pega la salida.

## Clientes (después)

No es un “préstamo”. Es software como servicio: un taller o un salón contrata el CRM y ve **solo sus contactos**. No se lleva la guía ni las 700 fichas. Hoy el único cliente sos vos (San Rafael 360).
